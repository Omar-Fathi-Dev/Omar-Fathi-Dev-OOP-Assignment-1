#### Problem 1679 — Max Number of K-Sum Pairs
Topic: Two Pointers

Approach:
- Sort the array.
- Use two pointers.
- Move the left or right pointer based on the sum.
- Count valid pairs.

Time Complexity: O(n log n)

Space Complexity: O(1)*
